コメント監視 — ホームページとプライバシーポリシー

このアプリについて

「コメント監視」は、運営者本人（エイキ）が自分の管理する YouTube チャンネルのコメントを確認するための、個人用ツールです。一般には公開しておらず、運営者本人以外は利用しません。

取得する情報

  • 運営者が管理するチャンネルの、コメント本文・投稿者名・投稿日時・動画情報
  • 運営者が管理するチャンネルの、動画の公開状態（公開・非公開・予約など）

YouTube からの取得は、読み取りのみです。

利用目的

不適切なコメントの検出と、運営者本人への通知（Slack）のみに使います。

行わないこと

  • コメントや動画の、削除・非表示・編集・投稿は行いません。
  • 取得した情報を、第三者に提供・販売することはありません。
  • 広告や、運営者本人の通知以外の目的には使いません。

外部サービスへの送信

不適切かどうかの判定のため、コメント本文を、AI サービス（Google Gemini）に送信します。通知のため、検出したコメントの内容を、運営者本人の Slack に送信します。

保存と管理

処理の状態（前回の確認位置など）と、確認待ちの一時的なコメント一覧は、運営者本人の Google Apps Script の領域にのみ保存します。API キーなどの認証情報は、同領域の非公開の設定で管理します。

Google API サービスのユーザーデータに関する方針

本アプリによる Google から受け取った情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に準拠します。
